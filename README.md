# ApexPlanet Internship – Task 2: Exploratory Data Analysis

## Project Overview
This project is part of the ApexPlanet Data Analytics Internship. The objective is to perform Exploratory Data Analysis (EDA), apply descriptive statistics, analyze data using SQL, and create meaningful visualizations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL Workbench
- SQL
- GitHub

## Project Tasks

### 1. Descriptive Statistics
- Calculated statistical summaries.
- Analyzed numerical data.
- Saved statistical results in CSV format.

### 2. Data Visualization
Created the following charts:
- Sales by Category
- Sales by Gender
- Top 10 Cities
- Quantity Distribution

### 3. SQL Analysis
Performed SQL-based analysis using 7 queries to explore the dataset and extract useful information.

### 4. Data Files
- `cleaned_dataset.csv`
- `statistical_summary.csv`

## Project Files
- `data_visualization.py` – Generates data visualizations.

- `eda.py` – Performs exploratory data analysis.
- `ApexPlanet_Task2_Analysis.sql` – Contains SQL analysis queries.
- `cleaned_dataset.csv` – Cleaned dataset.
